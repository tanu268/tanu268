## 🚀 Featured Projects

### 🔭 [KubeLens](https://github.com/tanu268/kubeLens)
An AI-powered Kubernetes observability platform with a **multi-agent architecture** (CPU, Memory, Anomaly, NLP). It features real-time pod resource discovery, network dependency mapping, and an NLP-driven insights dashboard. Built for the ABB Accelerator Hackathon.
> **Stack:** FastAPI, React, Kubernetes, OpenAI, Supabase, NetworkX

### 🚌 [BusGo](https://github.com/tanu268/BusGo)
A full-stack smart bus booking system featuring **AI route recommendations** and a RAG-powered chatbot. It utilizes ML for price prediction with urgency warnings and includes Razorpay payment integration.
> **Stack:** Django, React, LangChain, FAISS, scikit-learn, Ollama/Llama3

### ⚙️ [CodeMorph DB-AI](https://github.com/tanu268/codemorph-db-ai)
An AI-powered **database migration tool** that parses source code repositories to generate Oracle DDL. It provides index recommendations, scores schema compatibility, and exports full migration bundles.
> **Stack:** Django, React, Claude API, Oracle

### ☄️ Meteor Madness
An **asteroid impact visualization platform** utilizing NASA data datasets to track and map near-Earth objects. Built during the NASA Space Apps Challenge.
> **Stack:** Python, Data Visualization
